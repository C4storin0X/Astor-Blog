# Astor Blog

Personal cybersecurity blog and curated tools library.

## Content management

Content is managed through [Pages CMS](https://pagescms.org/) using the root `.pages.yml` configuration.

- `content/articles/`: technical articles in Markdown with YAML frontmatter.
- `content/tools/`: curated cybersecurity tools with metadata and technical notes.
- `media/`: uploaded images and other media.

## Publishing

Pages CMS writes content to this GitHub repository. A website generator and hosting service will be configured separately. Adding an article here does **not** publish a live website yet.

The upstream [mthcht/awesome-lists](https://github.com/mthcht/awesome-lists) is an external reference, not a fork or synchronized copy. Attribution and verification remain important.
